Installer l'application

  1. Appuyez sur le bouton de téléchargement ci-dessus (le fichier tango-kyc.apk se télécharge).
  2. Ouvrez le fichier téléchargé depuis les Notifications ou l'application Fichiers.
  3. Si Android le demande, autorisez l'installation depuis cette source (« Installer des applications inconnues » pour votre navigateur).
  4. Confirmez l'installation, puis ouvrez Tango KYC Verification.
